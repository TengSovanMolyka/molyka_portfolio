ABOUT THE PROJECT
-----------------

This is my personal portfolio website, created to showcase
my background, skills, creative work, academic projects,
and professional experience.

The portfolio is designed with a clean, modern, and
minimalist editorial style to provide visitors with a
simple and engaging browsing experience.

It serves as a digital space where recruiters, employers,
and visitors can explore my work and learn more about me.


TECHNOLOGIES USED
-----------------

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts


KEY FEATURES
------------

1. ABOUT ME
   Introduction, personal background, and professional profile.

2. EXPERIENCE
   Internship experience and professional responsibilities.

3. EDUCATION
   Academic background and educational history.

4. PROJECTS
   A collection of graphic design, multimedia, and academic
   projects.

5. PROJECT GALLERY
   Interactive project previews with image and video support,
   horizontal media navigation, and previous/next controls.

6. SKILLS & TOOLS
   Software knowledge, creative abilities, and professional
   strengths.

7. SOCIAL MEDIA
   Direct links to my LinkedIn, Facebook, Instagram, TikTok,
   and Telegram profiles.

8. CONTACT
   Contact information for professional communication.

HOW TO RUN LOCALLY
------------------

1. Download or clone the project to your computer.
2. Open the portfolio folder in Visual Studio Code.
3. Open index.html using Live Server.
4. The website will open in your default browser.


HOW TO UPDATE THE PORTFOLIO
---------------------------

To update the website:

- Edit index.html to change website content.
- Edit css/style.css to customize the appearance.
- Edit js/script.js to update interactive functionality.
- Add new images, icons, and videos inside the assets folder.
- Update project information and media paths when adding
  new portfolio projects.

Keep file names and relative paths correct to ensure that
all website resources load properly.


DEPLOYMENT
----------

The website can be published using Netlify.

For automatic deployment, connect the project repository
to GitHub and link the repository to Netlify.

After pushing new changes to the connected GitHub branch,
Netlify can automatically publish the updated website.
