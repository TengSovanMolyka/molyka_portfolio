TENG SOVANMOLYKA — PORTFOLIO

QUICK START
1. Extract this ZIP file.
2. Open index.html in Chrome, Edge, Firefox, or Safari.
3. The Resume button opens the included PDF.

PUBLISH ONLINE
Upload the extracted folder contents to your hosting provider (for example, GitHub Pages, Netlify, or your existing web hosting). Keep the assets folder beside index.html.

CUSTOMIZE YOUR PROJECTS
- Open index.html in a code editor.
- Find the section with id="work".
- Each project card is clearly marked with PROJECT 01, PROJECT 02, etc.
- Replace each placeholder visual with your own image, for example:
  <img src="assets/my-project.jpg" alt="Description of my project">
- Update the project title, category, and description in the same card.
- Keep image files inside assets (or update the image paths).

NOTES
- The portfolio uses responsive HTML, CSS, and JavaScript in one file.
- Google Fonts are loaded online; the layout remains usable if they are unavailable.
- Contact details and resume content are taken from the supplied CV.
- No unprovided client projects or school projects have been invented; all six gallery entries are labeled placeholders.
